# Melissa Ramos – Design Portfolio

Static HTML/CSS/JS site. No build step.

## Publish with GitHub Pages
1. Create a new repository and upload everything in this folder (keep the folder structure).
2. Go to Settings > Pages, choose the `main` branch and `/ (root)`, then save.
3. For a custom domain, add it in the same Pages settings and update your DNS as GitHub instructs.

## Edit
- `index.html` – home page; `case-study-1.html`, `case-study-2.html` – case study pages
- `css/` – styles; `js/` – menu and stat counter
- `images/` – your images (see the README there)
- Replace `hello@example.com` in `index.html` with your email.
